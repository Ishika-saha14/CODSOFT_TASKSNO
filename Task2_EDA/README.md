# Task 2: Exploratory Data Analysis (EDA)

## Objective
Analyze Titanic passenger data to identify survival patterns, distributions, relationships, and potential outliers.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Work Completed
- Examined dataset structure and descriptive statistics.
- Analyzed survival rates by gender and passenger class.
- Created four visualizations to explore survival and age distributions.
- Detected potential outliers in passenger age and ticket fare using the IQR method.
- Prepared a short EDA findings report.

## Files
- `CODSOFT_TASK2_EDA.ipynb` — analysis code and visualizations.
- `CODSOFT_TASK2_EDA_Report.txt` — summary of findings.

## Dataset
Titanic passenger dataset.

## Conclusion
This project explores passenger survival patterns and unusual values using descriptive statistics and visual analysis.
